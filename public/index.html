1 How It Works

Three steps to your
civic neighborhood

DM the bot your address. That's it.

01

Send your address

DM @nyc_civic on MMP with any NYC street address. The bot resolves your council district, assembly district, and election district.

02

Join your groups

The bot creates district group chats on demand and adds you automatically. Three tiers: city council, state assembly, and hyperlocal election district.

03

Get civic updates

Receive weekly 311 digests, new legislation alerts, vote results, and attendance reports directly in your group chats. Discuss with neighbors.

2 District Groups

Three tiers of
neighborhood

Every NYC address maps to multiple overlapping political districts. Each gets its own group chat.

Council District

NYC CD-{N}

e.g. NYC CD-1

City Council legislation, votes, attendance, and funding. Your most local elected representative.

51 districts citywide
Assembly District

NYC AD-{N}

e.g. NYC AD-65

311 complaint trends, crime summaries, community board meetings. State-level representation.

~150 districts citywide
Election District

NYC ED-{AD}-{ED}

e.g. NYC ED-65-042

Hyperlocal — your actual neighbors within a few blocks. Created on demand when the first person joins.

~6,000 districts citywide

5 API Reference

Developer API

The bot exposes REST endpoints for programmatic integration.

Base URL: https://nyc-civic-bot-production.up.railway.app

GET /health

Health check. Returns service status.

{ "status": "ok", "service": "nyc-civic-bot", "timestamp": "2026-03-30T19:25:51.004Z" }
GET /api/group/:key

Look up a district group by key (e.g. CD-1, AD-65, ED-65-042).

{ "district_key": "CD-1", "tier": "cd", "mmp_thread_id": "thr_abc123", "district_number": 1, "created_at": 1711828800 }
GET /api/groups?tier=cd|ad|ed

List all groups for a given tier. Returns an array of group objects.

[ { "district_key": "CD-1", "tier": "cd", ... }, { "district_key": "CD-2", "tier": "cd", ... } ]
POST /api/join

Programmatic onboarding — resolve an address and join the user to district groups.

// Request body { "mmp_user_id": "user_abc", "mmp_handle": "tim", "address": "250 Broadway, New York, NY" } // Response { "ok": true, "message": "Joined 3 groups: CD-1, AD-65, ED-65-042" }
POST /webhook/mmp

MMP webhook receiver. Processes incoming messages (DMs and group mentions). Verified via X-Webhook-Signature header.

// MMP webhook payload { "event": "message", "message": { "id": "msg_xyz", "from_handle": "tim", "body": "join 250 Broadway, NY", "is_group": false } }
